Choose a whale species, with clearer silhouettes.

- Added saved **Humpback / Orca** selection across ASCII, Hanzi and Kanji.
- Refined humpback flippers and their inset roots; both species now have curved tail flukes with a central notch.
- Added the orca’s broad head, rounded flippers and white eye/flank patches, independent of eye-background controls and compatible with custom body colors.
- Refreshed demo GIFs, including Kanji in both themes and species switching.
- GitHub Actions checks, packs and publishes the same tarball to npm and GitHub Releases.
