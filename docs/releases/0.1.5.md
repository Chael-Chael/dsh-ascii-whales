固定字符颗粒，自由调节鲸鱼游姿。

- 字符栅格采用固定 CSS 像素尺寸，调整窗口不再改变颗粒大小；默认栅格为 **1×**。

- 默认摆动幅度 **0.8**、转弯灵活度 **0.7**、摆尾频率 **0.8**；摆尾节奏独立于前进速度。

Fixed character grain, with adjustable whale movement.

- Cells use fixed CSS-pixel sizes independent of window width; default grid scale is **1×**.
- Added body swing amplitude (0–3), turning agility (0.1–3) and tail-beat frequency (0.1–5) across ASCII, Hanzi and Kanji.
- Defaults are **0.8 / 0.7 / 0.8** respectively. Tail rhythm is independent of travel speed.
- Swimming speed remains **0.65** and whale size **1.2**; all nine GIFs were re-recorded with the new defaults.
- Existing preferences are preserved. Choose **Restore defaults** to apply the new values.

验证 / Validation: typecheck, build and 10 tests pass. Isolated Edge checks cover motion controls, persistence and reset; all nine recordings pass with zero browser page errors. Desktop and other browsers were not tested.

安装 / Install:

```sh
dsh plugin --profile web add dsh-ascii-whales@0.1.5
```

Desktop 请通过客户端插件管理更新。For Desktop, update through the client plugin manager.
