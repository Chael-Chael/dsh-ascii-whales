鲸群只在对话里游，设置页重新排版。

- **聊天中显示鲸鱼** 与 **背景毛玻璃** 现在只在会话的「对话」标签页生效。切到轨迹、记忆、上下文、技能、编队、待办等其他标签页时，鲸鱼和雾面都会隐藏，插件面板不再被遮挡（[#2](https://github.com/Chael-Chael/dsh-ascii-whales/issues/2)）。新对话首页的海洋不受影响。
- 设置页分为 **显示 / 鲸群 / 外观 / 字体** 四张卡片，统一字号、间距、控件高度与分隔线，深浅主题均跟随 DSH；窄屏下自动改为单列。
- **海洋颜色** 支持直接输入 hex（可省略 `#`），输入合法色值即时生效，失焦时不合法的输入会恢复为当前颜色。
- 颜色色块恢复为正圆；「字体」一行更名为 **字体来源**。

Whales now stay in the chat, and the settings page has a new layout.

- **Show whales in chat** and the **frosted-glass chat background** now apply only to the conversation's Chat tab. Switching to Trajectory, Memory, Context, Skills, Team, Todos or other plugin tabs hides both the ocean and the mist, so plugin panels are no longer covered ([#2](https://github.com/Chael-Chael/dsh-ascii-whales/issues/2)). The ocean on the empty new-chat page is unchanged.
- Settings are grouped into **Display / Whales / Look / Font** cards with consistent type, spacing, control height and dividers, following DSH in both themes; narrow windows switch to a single column.
- **Ocean color** accepts a typed hex value (the `#` is optional). Valid colors apply immediately; invalid input reverts to the current color on blur.
- Color swatches are round again, and the font row is renamed **Font source**.

验证 / Validation: typecheck, build and 13 tests pass, including the Chat-view-only ocean and mist. Every conversation tab, the global pages and the settings page were checked in an isolated DSH Web 0.2.2-rc.1 instance (Edge) with dsh-context 0.84.1 and dsh-memory-evolve 0.1.0. Not yet verified on macOS DSH Desktop.

安装 / Install:

```sh
dsh plugin --profile web add dsh-ascii-whales@0.1.7
```
